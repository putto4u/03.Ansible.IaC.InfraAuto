깃허브(GitHub)에서 타인의 저장소(Repository)에 기여하거나 코드를 올리는 방법은 크게 두 가지 권한 모델로 나뉩니다. 단순히 '키(Key)'를 받는 것 이상의 권한 설정과 인증 절차가 필요합니다.

---

## 깃허브 협업을 위한 권한 및 인증 구조

타인의 저장소에 코드를 올리기(Push) 위해서는 해당 저장소의 **쓰기 권한(Write Access)**이 있어야 하며, 동시에 본인임을 증명하는 **인증(Authentication)** 과정을 거쳐야 합니다.

### 1. 협업 방식의 분류

| 방식 | 설명 | 권한 설정 | 주요 사용 처 |
| --- | --- | --- | --- |
| **Collaborator 등록** | 소유자가 사용자를 협업자로 직접 추가 | 저장소 소유자가 초대 메일 발송 및 수락 필요 | 팀 프로젝트, 소규모 협업 |
| **Fork & Pull Request** | 타인의 저장소를 내 계정으로 복제 후 수정 | 권한 불필요 (내 저장소에 Push 후 PR 요청) | 오픈 소스 기여, 대규모 프로젝트 |

---

## 인증 방법: '키(Key)'와 '토큰(Token)'

깃허브는 보안상의 이유로 일반 비밀번호를 통한 Push를 허용하지 않습니다. 따라서 다음 중 하나의 방법을 반드시 선택하여 설정해야 합니다.

### 1. SSH 키 (Secure Shell Key)

보안 연결을 위한 공개키 암호화 방식입니다. 본인의 컴퓨터에서 생성한 '공개키'를 깃허브 서버에 등록하면, 이후 비밀번호 입력 없이 안전하게 통신할 수 있습니다.

* **용도:** 개인 PC에서 지속적으로 작업할 때 권장.
* **특징:** 한 번 등록하면 해당 PC의 모든 깃 작업에 적용됩니다.

### 2. Personal Access Token (PAT)

비밀번호를 대신하는 일종의 임시 비밀번호입니다. 깃허브 웹사이트에서 생성하여 사용합니다.

* **용도:** SSH 설정이 번거롭거나 특정 권한만 임시로 부여하고 싶을 때 사용.
* **특징:** 유효 기간을 설정할 수 있으며, 만료 시 재생성해야 합니다.

## 협업자로 참여하여 코드 올리는 절차

### Step 1: 협업자 초대 및 수락

1. 저장소 소유자가 `Settings` > `Collaborators` > `Add people`에서 사용자의 ID 또는 이메일을 입력하여 초대합니다.
2. 사용자는 이메일 또는 깃허브 알림을 통해 초대를 **Accept(수락)** 해야 합니다. 수락 전에는 쓰기 권한이 활성화되지 않습니다.

### Step 2: 로컬 환경 인증 설정 (SSH 기준)

이미 키를 가지고 있다면 등록만 하면 되고, 없다면 새로 생성해야 합니다.

1. **키 생성 (터미널/CMD):**
```bash
ssh-keygen -t ed25519 -C "your_email@example.com"

```


*입력 창이 나오면 엔터를 눌러 기본 경로에 저장합니다.*
2. **공개키 복사:**
* Windows: `type %userprofile%\.ssh\id_ed25519.pub`
* Linux/Mac: `cat ~/.ssh/id_ed25519.pub`
* 출력된 `ssh-ed25519 ...`으로 시작하는 문자열을 전체 복사합니다.


3. **깃허브 등록:**
* `Settings` > `SSH and GPG keys` > `New SSH key` 클릭 후 복사한 내용을 붙여넣습니다.



### Step 3: 저장소 클론 및 푸시

```bash
# SSH 주소를 복사하여 클론
git clone git@github.com:owner/repository.git

# 코드 수정 후
git add .
git commit -m "commit message"

# 원격 저장소로 전송
git push origin main

```

## 요약 및 주의사항

* **권한 확인:** 소유자가 나를 'Collaborator'로 추가했는지 확인하십시오.
* **인증 수단:** SSH 키 또는 Personal Access Token 중 하나가 반드시 로컬 PC에 설정되어 있어야 합니다.
* **보안:** 생성된 **개인키(Private Key)**나 **토큰(Token)**은 절대로 타인에게 공유하거나 깃허브 코드 내에 포함시켜 올리지 않도록 주의해야 합니다.
