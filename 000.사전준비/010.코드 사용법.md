VS Code는 단순한 텍스트 에디터를 넘어 개발 생산성을 극대화할 수 있는 다양한 편의 기능을 내장하고 있습니다. 효율적인 워크플로우를 위한 핵심 기능들을 정리합니다.

---
## 1. YAML 가독성을 위한 세로줄 설정 (최우선 설정)

YAML은 단 한 칸의 들여쓰기 실수로도 문법 오류가 발생합니다. 이를 방지하기 위해 세로 가이드라인을 강하게 설정하는 것이 필수적입니다.

* **인덴트 가이드 활성화**: `Editor: Guides Indentation` 설정을 켜면 들여쓰기 단계마다 수직 점선이 표시되어 부모-자식 관계를 한눈에 보여줍니다.
* **활성 블록 강조 (`Bracket Pair Guides`)**: 현재 커서가 위치한 계층의 세로줄을 다른 색상으로 강조하여, 복잡한 YAML 구조 안에서 길을 잃지 않게 돕습니다.
* **고정 눈금자 (Rulers)**: `settings.json`에서 `"editor.rulers": [2, 4, 6, 8]`와 같이 설정하면 YAML의 표준 들여쓰기 단위인 2칸/4칸마다 뚜렷한 세로 실선을 그어 가이드로 삼을 수 있습니다.

---

## 2. YAML 전용 편의 기능 및 확장

세로줄 설정과 함께 사용하면 시너지가 발생하는 기능들입니다.

* **YAML 확장 프로그램 (by Red Hat)**: YAML 문법 검사, 자동 완성, 문서 포맷팅을 지원합니다. (**무료**)
* **자동 포맷팅 (`Format on Save`)**: 파일을 저장할 때마다 들여쓰기 규칙에 맞춰 코드를 자동으로 정렬해 줍니다.
* **접기 기능 (Folding)**: `+`, `-` 버튼을 눌러 특정 계층 전체를 접거나 펼 수 있어 긴 설정 파일을 관리하기 용이합니다.



## 1. 멀티 커서 및 영역 선택

동일한 단어를 동시에 수정하거나 여러 줄에 걸쳐 같은 코드를 입력할 때 유용합니다.

* **멀티 커서 생성**: `Alt + 클릭`을 하면 클릭하는 곳마다 커서가 생깁니다.
* **동일 단어 동시 선택**: 단어를 드래그한 후 `Ctrl + D`를 누르면 아래에 있는 동일한 단어를 하나씩 추가로 선택합니다. 한꺼번에 모두 선택하려면 `Ctrl + Shift + L`을 누릅니다.
* **세로줄 선택 (Column Selection)**: `Shift + Alt + 마우스 드래그`를 하면 세로 블록 단위로 코드를 선택하고 편집할 수 있습니다.

---

## 2. 빠른 이동 및 검색 (Command Palette)

마우스를 쓰지 않고 키보드만으로 대부분의 기능을 실행할 수 있습니다.

* **전체 명령 실행 (`Ctrl + Shift + P`)**: 모든 기능(설정, 확장 설치, 셸 명령 등)을 검색하여 실행하는 통합 창입니다.
* **파일 바로 가기 (`Ctrl + P`)**: 프로젝트 내의 파일명을 입력하여 즉시 해당 파일을 엽니다.
* **심볼 이동 (`Ctrl + Shift + O`)**: 현재 파일 내의 함수나 변수 목록을 보고 원하는 위치로 즉시 점프합니다.

---

## 3. 코드 인텔리전스 (IntelliSense)

단순한 자동 완성을 넘어 코드의 문맥을 분석하여 정보를 제공합니다.

* **매개변수 정보**: 함수를 작성할 때 필요한 인자의 타입과 설명을 팝업으로 보여줍니다.
* **정의로 이동 (`F12`)**: 함수나 변수가 선언된 실제 소스 코드 위치로 즉시 이동합니다.
* **미리 보기 (`Alt + F12`)**: 화면을 이동하지 않고 작은 창을 띄워 해당 함수의 내용을 확인합니다.

---

## 4. 내장 터미널 및 버전 관리 (Git)

외부 창으로 나가지 않고 에디터 내부에서 모든 작업을 완결할 수 있습니다.

* **통합 터미널 (`Ctrl + ` ` `)**: 별도의 터미널 앱 없이 바로 명령어를 실행합니다. AWS 서버에 접속한 상태라면 여기서 바로 리눅스 명령어를 입력합니다.
* **Git 소스 제어**: 변경된 코드 줄 옆에 파란색(수정), 초록색(추가) 바가 표시됩니다. 왼쪽 소스 제어 탭에서 클릭 한 번으로 커밋(Commit)과 푸시(Push)가 가능합니다.

---

## 5. 지능형 코드 조각 (Snippets)

자주 사용하는 코드 패턴을 짧은 키워드로 입력합니다.

* 예를 들어 `log`를 입력하고 `Tab`을 누르면 `console.log();`가 자동으로 완성되도록 설정할 수 있습니다.
* 사용자 정의 스니펫을 통해 본인이 자주 쓰는 AWS 인프라 설정 코드나 반복되는 HTML 구조를 등록해 사용할 수 있습니다.

---

## 6. 비용 및 성능 안내

* **비용**: 위에서 언급된 모든 기능은 VS Code의 기본 내장 기능으로 **완전 무료**입니다.
* **성능**: 많은 확장을 설치하면 메모리 점유율이 높아질 수 있으므로, 사용하지 않는 확장은 비활성화(Disable)하는 것이 좋습니다.
