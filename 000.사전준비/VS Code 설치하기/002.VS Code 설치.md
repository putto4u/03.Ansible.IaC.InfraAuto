VS Code(Visual Studio Code)는 마이크로소프트에서 개발한 오픈 소스 기반의 코드 편집기로, 다양한 프로그래밍 언어와 확장 기능을 지원합니다. 각 운영체제별 설치 방법과 초기 설정 환경을 정리합니다.

---

## 1. 운영체제별 설치 방법

### Windows 환경

1. [VS Code 공식 홈페이지](https://code.visualstudio.com/)에 접속합니다.
2. **Download for Windows** 버튼을 클릭하여 설치 파일(`.exe`)을 다운로드합니다.
3. 설치 프로그램을 실행한 후 아래 옵션을 반드시 체크하는 것을 권장합니다:
* **PATH에 추가(설치 후 다시 시작 필요)**: 터미널에서 `code` 명령어로 바로 실행할 수 있게 합니다.
* **내용 메뉴에 'Code(으)로 열기' 작업 추가**: 폴더나 파일을 우클릭하여 즉시 편집할 수 있습니다.



### macOS 환경

1. 홈페이지에서 **Download for Mac**을 클릭하여 압축 파일(`.zip`)을 받습니다.
2. 압축을 풀고 생성된 `Visual Studio Code.app` 파일을 **응용 프로그램(Applications)** 폴더로 드래그하여 이동시킵니다.
3. `Command + Space`로 스포트라이트를 켜고 'Visual Studio Code'를 실행합니다.

### Linux 환경 (Ubuntu/Debian 기준)

터미널에서 다음 명령어를 통해 설치할 수 있습니다.

```bash
sudo apt update
sudo apt install software-properties-common apt-transport-https wget
wget -q https://packages.microsoft.com/keys/microsoft.asc -O- | sudo apt-key add -
sudo add-apt-repository "deb [arch=amd64] https://packages.microsoft.com/repos/vscode stable main"
sudo apt install code

```

## 2. 필수 초기 설정 (SSH 및 개발 환경)

설치가 완료된 후, 앞서 배운 AWS 서버 접속 및 코드 편집을 위해 다음 확장 도구를 설치해야 합니다.

1. **Korean Language Pack**: VS Code 메뉴를 한국어로 변경합니다.
2. **Remote - SSH**: AWS EC2와 같은 원격 서버에 SSH로 접속하여 로컬 컴퓨터처럼 코딩할 수 있게 해주는 핵심 확장 기능입니다. (**무료**)
3. **Prettier / ESLint**: 코드 스타일 자동 교정 및 오류 검사 도구입니다.

---

## 3. SSH 키 연결 설정

앞서 생성한 `.pem` 키를 사용하여 VS Code에서 서버에 바로 접속하는 방법입니다.

1. VS Code 왼쪽 하단의 **[><] (Open a Remote Window)** 아이콘을 클릭합니다.
2. **Connect to Host...** -> **Configure SSH Hosts...**를 선택합니다.
3. 설정 파일(`~/.ssh/config`)에 다음 내용을 입력하고 저장합니다.
```text
Host my-aws-server
    HostName <서버의 공인 IP>
    User ubuntu (또는 ec2-user)
    IdentityFile <나의 pem 키 경로>

```

## 4. 비용 안내

* **VS Code 소프트웨어**: **무료** (오픈 소스 및 커뮤니티 에디션 포함)
* **확장 프로그램**: Remote-SSH를 포함한 대부분의 공식 확장은 **무료**입니다.
* **네트워크**: 원격 접속 시 발생하는 데이터 전송량은 AWS의 데이터 전송(Out) 비용에 포함될 수 있으나, 일반적인 코드 편집 수준에서는 미미합니다.
