VS Code를 효율적으로 활용하기 위한 가장 기초적이고 필수적인 동작 원리를 정리합니다. 이 단계에 익숙해지면 마우스 사용량을 줄이고 코드 편집 속도를 획기적으로 높일 수 있습니다.

---

## 1. 인터페이스 핵심 구성

화면 각 요소의 명칭과 용도를 이해하는 것이 첫걸음입니다.

* **활동 바(Activity Bar)**: 맨 왼쪽 아이콘들로, 탐색기, 검색, 소스 제어(Git), 실행 및 디버그, 확장(Extensions) 메뉴를 전환합니다.
* **사이드바(Sidebar)**: 활동 바에서 선택한 메뉴의 상세 내용(파일 목록 등)이 표시됩니다. `Ctrl + B`로 켜고 끌 수 있어 화면을 넓게 쓸 때 유용합니다.
* **에디터 영역(Editor)**: 실제 코드를 작성하는 공간입니다. `Ctrl + \`를 눌러 화면을 최대 3개까지 가로로 분할하여 서로 다른 파일을 동시에 볼 수 있습니다.
* **패널(Panel)**: 하단의 터미널, 출력, 디버그 콘솔 등이 위치합니다. `Ctrl + ` ` `(백틱)으로 터미널을 즉시 여닫을 수 있습니다.

---

## 2. 파일 관리 및 탐색 (Search & Open)

폴더 구조를 일일이 클릭하는 대신 검색 기능을 생활화해야 합니다.

* **빠른 열기 (`Ctrl + P`)**: 파일명만 입력하여 프로젝트 내 어떤 파일이든 즉시 이동합니다.
* **전체 검색 (`Ctrl + Shift + F`)**: 특정 단어가 포함된 모든 파일을 찾고, 필요한 경우 한꺼번에 치환(Replace)할 수 있습니다.
* **기호 이동 (`Ctrl + Shift + O`)**: 현재 파일 내의 특정 함수나 설정 키값으로 즉시 점프합니다.

---

## 3. 코드 편집 기술 (Editing)

작성 효율을 높여주는 핵심 동작들입니다.

* **줄 복사 및 이동**:
* `Alt + ↑ / ↓`: 현재 커서가 있는 줄을 위아래로 옮깁니다.
* `Shift + Alt + ↑ / ↓`: 현재 줄을 위아래에 복제합니다.


* **동일 단어 선택 (`Ctrl + D`)**: 같은 변수명을 한꺼번에 바꿀 때 유용합니다. 단어를 선택하고 `Ctrl + D`를 반복해서 누르면 아래의 동일 단어들이 순차적으로 선택됩니다.
* **코드 주석 처리 (`Ctrl + /`)**: 선택한 영역을 현재 언어 문법에 맞는 주석으로 즉시 전환합니다.

---

## 4. 세로 가이드 활용 (YAML 및 구조 파악)

앞서 강조한 세로줄 기능을 실제 편집에 적용하는 방법입니다.

* **인덴트 라인 확인**: 코드 왼쪽에 수직으로 내려오는 점선을 따라가며 현재 내가 작성 중인 코드가 어느 블록(`if`, `loop`, `YAML key`)에 속해 있는지 수시로 확인합니다.
* **블록 접기/펴기**: 세로줄 왼쪽의 작은 화살표를 눌러 현재 보지 않는 긴 코드 블록을 숨겨 시야를 확보합니다.

Visual Studio Code(VS Code)는 개발자의 생산성을 결정짓는 핵심 도구입니다. 효율적인 워크플로우를 위해 기본 단축키를 익히는 것을 넘어, 본인의 작업 스타일에 맞춰 키 바인딩을 최적화하고 환경 설정을 구성하는 방법을 정리합니다.

---

## 1. 단축키 설정 방식 이해

VS Code에서 단축키를 설정하는 방법은 크게 두 가지입니다.

### 1.1 UI를 통한 설정 (Keyboard Shortcuts)

가장 직관적인 방법으로, 명령어를 검색하고 원하는 키 조합을 입력하여 설정합니다.

* **진입 경로:** `File` > `Preferences` > `Keyboard Shortcuts` (단축키: `Ctrl+K Ctrl+S`)
* **특징:** 현재 설정된 모든 단축키를 한눈에 볼 수 있으며, 중복 여부를 바로 확인할 수 있습니다.

### 1.2 JSON 파일을 통한 직접 수정 (keybindings.json)

고급 사용자를 위한 방식으로, 세부적인 조건(`when` 절)을 부여하여 특정 상황에서만 동작하는 단축키를 만들 수 있습니다.

* **진입 경로:** 단축키 설정 UI 우측 상단의 **Open Keyboard Shortcuts (JSON)** 아이콘 클릭
* **포맷 예시:**
```json
[
    {
        "key": "ctrl+shift+d",
        "command": "editor.action.duplicateSelection"
    }
]

```



---

## 2. 생산성을 높이는 필수 커스터마이징 추천

기본 설정에는 없거나, 변경했을 때 효율이 극대화되는 단축키 설정 예시입니다.

| 기능 | 추천 단축키 | 명령어 (Command ID) |
| --- | --- | --- |
| **줄 복제 (Duplicate)** | `Ctrl+Shift+D` | `editor.action.duplicateSelection` |
| **터미널 열기/닫기** | `Ctrl+` (Backtick) | `workbench.action.terminal.toggleTerminal` |
| **파일 탐색기 포커스** | `Ctrl+Shift+E` | `workbench.view.explorer` |
| **심볼로 이동** | `Ctrl+Shift+O` | `workbench.action.gotoSymbol` |
| **선택 영역 주석 처리** | `Ctrl+/` | `editor.action.commentLine` |

---

## 3. 핵심 환경 설정 (settings.json)

단축키 외에도 `settings.json`을 통해 코드 편집 환경을 최적화할 수 있습니다. `Ctrl+,`를 눌러 설정 창을 열고, 우측 상단 JSON 아이콘을 클릭하여 다음 설정을 검토하세요.

### 3.1 편집기 기본 설정

```json
{
    "editor.fontSize": 14,                // 폰트 크기
    "editor.tabSize": 4,                  // 탭 간격
    "editor.insertSpaces": true,          // 탭 대신 스페이스 사용
    "editor.formatOnSave": true,          // 저장 시 자동 코드 정렬
    "editor.minimap.enabled": false,      // 미니맵 제거 (화면 넓게 사용)
    "editor.stickyScroll.enabled": true   // 스크롤 시 함수/클래스명 상단 고정
}

```

### 3.2 탐색기 및 창 설정

```json
{
    "explorer.confirmDelete": false,      // 파일 삭제 시 확인 창 끄기
    "workbench.startupEditor": "none",    // 시작 시 환영 페이지 표시 안 함
    "files.autoSave": "afterDelay",       // 일정 시간 후 자동 저장
    "files.exclude": {                    // 탐색기에서 숨길 파일
        "**/.git": true,
        "**/node_modules": true
    }
}

```

## 4. 설정 동기화 (Settings Sync)

여러 PC를 사용하거나 포맷 후 환경을 복구해야 할 때 유용합니다.

* **방법:** 좌측 하단 **Manage (톱니바퀴 아이콘)** > **Turn on Settings Sync** 클릭
* **연동:** GitHub 또는 Microsoft 계정을 통해 단축키, 설정, 확장 프로그램을 클라우드에 백업하고 공유할 수 있습니다.

---

VS Code의 효율적인 사용법은 단순히 기능을 아는 것을 넘어, 손이 기억하도록 **단축키와 워크플로우를 체득**하는 과정입니다. 개발 생산성을 2배 이상 높여주는 실무 중심의 익숙해지기 단계를 정리합니다.

---

## 1. 세로 가이드와 들여쓰기 최적화 (가장 먼저 익숙해지기)

코드의 구조를 파악하는 '눈'을 기르는 설정입니다. 특히 YAML이나 파이썬처럼 들여쓰기가 중요한 언어에서 필수적입니다.

* **가이드라인 고정**: `settings.json`에 `"editor.rulers": [2, 4]`를 설정하여 시각적인 벽을 만드세요. 코드가 이 선을 넘지 않도록 관리하는 습관을 들입니다.
* **들여쓰기 강조**: `Editor: Guides Bracket Pairs`를 `active`로 설정하여 현재 수정 중인 블록의 세로줄 색상을 다르게 표시합니다.
* **공백 시각화**: `Editor: Render Whitespace`를 `all`로 설정하면 스페이스와 탭이 점으로 표시되어 미세한 들여쓰기 오류를 즉시 잡아낼 수 있습니다.

---

## 2. 마우스를 버리는 키보드 워크플로우

손의 동선을 최소화하는 것이 '숙련자'로 가는 지름길입니다.

* **파일 찾기 (`Ctrl + P`)**: 왼쪽 탐색기에서 파일을 찾으려 하지 말고, 파일명 일부만 입력하여 즉시 이동하세요.
* **줄 이동 및 복사**:
* `Alt + ↑/↓`: 현재 줄을 위아래로 이동시킵니다.
* `Shift + Alt + ↑/↓`: 현재 줄을 그대로 복사하여 위아래에 붙입니다.


* **빠른 주석 (`Ctrl + /`)**: 여러 줄을 선택하고 한 번에 주석 처리를 하거나 해제하는 연습을 하세요.

---

## 3. 코드 네비게이션과 심볼 탐색

수천 줄의 코드 사이에서 원하는 로직을 찾는 방법입니다.

* **정의 확인 및 이동**: 변수나 함수 위에 커서를 두고 `F12`를 누르면 선언부로 이동하며, `Alt + F12`를 누르면 현재 화면을 유지한 채 작은 창으로 내용을 보여줍니다.
* **기호 검색 (`Ctrl + Shift + O`)**: 현재 파일에 있는 모든 함수나 변수 목록을 띄워 검색합니다.
* **전체 검색 (`Ctrl + Shift + F`)**: 프로젝트 전체에서 특정 키워드가 포함된 모든 파일을 찾아냅니다.

---

## 4. 터미널과 Git의 일상화

에디터 하단의 터미널(`Ctrl + ` ` `)을 별도의 프로그램처럼 활용하세요.

* **AWS 접속 유지**: 터미널에서 SSH로 서버에 접속한 상태를 유지하며 코드를 수정하고 바로 실행 결과를 확인합니다.
* **Git 타임라인**: 왼쪽 '소스 제어' 탭을 통해 코드의 변경 이력을 수시로 확인하고, 의미 있는 단위로 커밋하는 습관을 들입니다.
