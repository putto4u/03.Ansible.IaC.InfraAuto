`ansible-vault encrypt` 또는 `edit` 명령을 실행했을 때 비밀번호를 묻는 것은 정상적인 보안 절차입니다. 하지만 매번 수동으로 비밀번호를 입력하는 것은 자동화의 효율성을 떨어뜨리므로, **비밀번호 파일(`.vault_pass`)을 사용하여 이를 자동화**하는 실무 설정법을 안내해 드립니다.

---

## 1. Vault 비밀번호 자동화 설정

비밀번호를 파일에 저장하고 Ansible이 이를 자동으로 읽어가도록 설정하면, 더 이상 터미널에서 비밀번호를 묻지 않습니다.

### **Step 1: 비밀번호 파일 생성**

프로젝트 루트 디렉토리에 암호화 시 사용했던 비밀번호를 텍스트 파일로 저장합니다.

```bash
# ~/projects/ans_pj1 경로에서 실행
echo "여러분이_설정한_비밀번호" > .vault_pass

# 보안을 위해 소유자만 읽을 수 있도록 권한 제한 (필수)
chmod 600 .vault_pass

```

### **Step 2: ansible.cfg에 등록**

Ansible이 실행될 때 해당 파일을 참조하도록 설정 파일에 경로를 추가합니다.

```ini
# ansible.cfg
[defaults]
inventory = ./hosts
vault_password_file = ./.vault_pass  # 비밀번호 파일 경로 지정

```

이렇게 설정하면 이후 `ansible-vault edit`이나 `ansible-playbook` 실행 시 **비밀번호를 묻지 않고 즉시 실행**됩니다.
