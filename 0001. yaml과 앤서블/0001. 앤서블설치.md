## 앤서블(Ansible) 설치 및 환경 구성

앤서블은 **제어 노드(Control Node)**에만 설치하면 되며, 관리 대상이 되는 서버(Managed Node)에는 별도의 에이전트를 설치할 필요가 없습니다. 이 섹션에서는 리눅스 환경에서의 표준 설치 방법과 초기 설정 과정을 다룹니다.

---

### 1. 운영체제별 설치 방법

앤서블은 파이썬(Python) 기반으로 동작하므로, 시스템에 파이썬이 설치되어 있어야 합니다.

#### 1.1 Ubuntu / Debian 계열

공식 PPA(Personal Package Archive)를 추가하여 최신 안정 버전을 설치하는 것을 권장합니다.

```bash
sudo apt update
sudo apt install software-properties-common -y
sudo add-apt-repository --yes --update ppa:ansible/ansible
sudo apt install ansible -y

```

#### 1.2 RHEL / CentOS / Rocky Linux 계열

EPEL(Extra Packages for Enterprise Linux) 저장소를 먼저 활성화해야 합니다.

```bash
sudo dnf install epel-release -y
sudo dnf install ansible -y

```

#### 1.3 macOS

Homebrew를 통해 간편하게 설치할 수 있습니다.

```bash
brew install ansible

```

---

### 2. 설치 확인 및 버전 체크

설치가 완료되면 다음 명령어를 통해 정상 작동 여부를 확인합니다.

```bash
ansible --version

```

* **python version**: 앤서블이 사용하는 파이썬 경로와 버전을 확인할 수 있습니다.
* **config file**: 현재 적용 중인 설정 파일(`ansible.cfg`)의 위치를 보여줍니다.

---

### 3. 인벤토리(Inventory) 및 SSH 설정

앤서블이 대상 서버에 접속하기 위해서는 대상 서버의 목록이 담긴 **인벤토리** 파일이 필요합니다.

1. **인벤토리 파일 생성 (`/etc/ansible/hosts.ini`)**:
```ini
[web_servers]
192.168.0.10
192.168.0.11

```


2. **SSH 키 복사**: 앤서블은 비밀번호 없이 SSH 키를 통해 접속하는 환경에서 가장 잘 작동합니다.
```bash
ssh-keygen -t rsa  -f rsa000   # 키가 없는 경우 생성
ssh-copy-id user@192.168.0.10  # 대상 서버로 키 전송

```



---

### 4. 첫 번째 통신 테스트 (Ping)

모든 설정이 완료되었다면 `ping` 모듈을 사용하여 연결을 확인합니다. 이는 네트워크 ICMP 핑이 아니라, 앤서블이 대상 서버에 파이썬을 실행할 수 있는지 확인하는 테스트입니다.

```bash
ansible all -i hosts.ini -m ping

```

* **성공 시**: `"ping": "pong"` 메시지가 출력됩니다.

---

### 5. 인프라 운영 시 주의사항 (AWS 관련)

> **[주의: AWS 과금 및 보안]**
> * **Bastion Host 활용**: AWS 환경에서 Private Subnet에 있는 인스턴스들에 앤서블을 실행하려면 **Bastion Host**를 경유해야 합니다. 이때 SSH 터널링 설정을 잘못하면 외부 노출 위험이 있으므로 보안 그룹 설정을 엄격히 관리해야 합니다.
> * **Dynamic Inventory 비용**: AWS 인스턴스 목록을 자동으로 가져오는 'Dynamic Inventory' 기능을 사용할 때, API 호출 횟수가 극단적으로 많아지면 미세하게 **CloudWatch 또는 API 요청 비용**이 발생할 수 있습니다. (일반적인 규모에서는 미미합니다.)
> * **EC2 인스턴스 스펙**: 제어 노드로 사용하는 EC2 인스턴스가 너무 낮은 사양(t2.nano 등)일 경우, 많은 수의 서버에 동시에 플레이북을 실행하면 메모리 부족으로 프로세스가 중단될 수 있습니다.
