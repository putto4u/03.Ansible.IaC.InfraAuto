버추얼박스(VirtualBox)가 설치된 여러 대의 PC에 우분투(Ubuntu)를 설치한다고 가정합시다.



### 1. 테라폼(Terraform) vs 앤서블(Ansible) 역할 비교

| 구분 | 테라폼 (Terraform) | 앤서블 (Ansible) |
| --- | --- | --- |
| **주요 역할** | **인프라 프로비저닝** (VM 생성) | **구성 관리** (OS 설정 및 소프트웨어 설치) |
| **강점** | VM의 개수, CPU, 메모리, 네트워크 등 **'형체'를 만드는 것**에 최적화 | 생성된 VM 안에 패키지를 깔고 설정 파일을 수정하는 **'내용'을 채우는 것**에 최적화 |
| **상태 관리** | **State 파일**을 통해 현재 몇 대의 VM이 떠 있는지 기억하고 관리함 | 현재 상태를 기억하기보다 명령을 수행하여 원하는 상태로 만듦 |
| **VirtualBox 연동** | [VirtualBox Provider](https://registry.terraform.io/providers/terra-farm/virtualbox/latest/docs)를 통해 코드로 VM 생성 가능 | 이미 생성되어 SSH 접속이 가능한 상태의 VM에만 명령 가능 |

---

### 2. 테라폼을 이용한 설치 방식 (추천: 인프라 생성 단계)

PC에 이미 VirtualBox가 설치되어 있다면, 테라폼의 `virtualbox_vm` 리소스를 사용하여 우분투 VM을 대량으로 생성할 수 있습니다.

* **방법:** 우분투 이미지(.iso 또는 .box)를 지정하고, 코드에서 `count = 10`과 같이 설정하면 10대의 우분투 VM이 자동으로 생성됩니다.
* **장점:** VM의 스펙(RAM 2GB, CPU 2개 등)을 일관되게 유지할 수 있고, 나중에 VM을 삭제하거나 늘릴 때도 코드 한 줄로 제어 가능합니다.
* **단점:** VM을 '생성'하는 것까진 쉽지만, 생성된 OS 내부의 세세한 설정(사용자 추가, 특정 앱 설치 등)을 하기에는 앤서블보다 불편합니다.

---

### 3. 앤서블을 이용한 설치 방식 (추천: OS 설정 단계)

앤서블은 기본적으로 **"대상 서버에 IP로 접속할 수 있다"**는 전제하에 작동합니다. 즉, VM이 아직 만들어지지도 않은 상태에서 우분투를 '설치'하는 용도로는 적합하지 않습니다.

* **방법:** 이미 수동이나 스크립트로 생성된 우분투 VM들에 SSH로 접속하여 필요한 패키지를 설치하고 업데이트합니다.
* **장점:** 100대의 우분투에 동시에 `apt update`를 하거나 특정 보안 설정을 적용하는 데 독보적입니다.
* **단점:** 버추얼박스 자체를 제어하여 VM을 새로 만드는 기능은 테라폼에 비해 약합니다.

---

### 4. 가장 권장하는 실무 시나리오 (Best Practice)

실제 IT 전문가들은 이 두 도구를 **파이프라인**으로 엮어서 사용합니다.

1. **테라폼(Terraform):** 버추얼박스 위에 우분투 VM 10대를 순식간에 **생성**합니다. 이때, 부팅 후 바로 SSH 접속이 가능하도록 기초 설정만 넣습니다.
2. **앤서블(Ansible):** 테라폼이 만든 10대의 VM에 접속하여 보안 패치, 한글 설정, 필요한 소프트웨어(Docker, Python 등)를 **일괄 설치**합니다.


**결론적으로 말한다면 두 도구를 함께 사용하는 것이 가장 이상적이나, 굳이 하나를 선택한다면 테라폼(Terraform)이 '설치(생성)' 단계에 더 적합합니다.**

두 도구는 설계 목적 자체가 다르기 때문입니다.

### 💡 요약 및 선택 가이드

* **"나는 클릭 한 번으로 VM 20개를 만들고 싶다"** → **테라폼**을 공부하세요.
* **"이미 만들어진 VM 20대에 한꺼번에 프로그램을 깔고 싶다"** → **앤서블**을 공부하세요.
* **"완전 자동화를 꿈꾼다"** → **테라폼으로 VM을 만들고, 앤서블로 내부를 세팅**하는 조합이 정답입니다.

> **용어 코멘트**
> * **프로비저닝(Provisioning):** 사용할 수 있는 상태의 IT 인프라(서버, 네트워크 등)를 준비해 놓는 과정입니다.
> * **Provider (프로바이더):** 테라폼이 특정 서비스(VirtualBox, AWS, Azure 등)와 대화할 수 있게 해주는 통역사 역할을 하는 플러그인입니다.
