## Gitea 실행 및 웹 인터페이스 접속 가이드

바이너리 파일을 다운로드한 후, 서비스를 실행하고 웹 브라우저를 통해 초기 설정 페이지에 접속하는 과정을 단계별로 설명합니다.

---

### 1. Gitea 실행 및 초기 확인

다운로드한 바이너리에 실행 권한을 부여하고 실행하는 과정입니다.

```bash
# 1. 실행 권한 부여
chmod +x gitea

# 2. 웹 서버 모드로 실행
./gitea web

```

실행 후 터미널 로그에 `Listening on http://0.0.0.0:3000` 문구가 나타나면 Gitea 서버가 정상적으로 대기 상태에 들어간 것입니다.

---

### 2. 인터넷 웹 브라우저 접속 방법

Gitea는 기본적으로 **3000번 포트**를 사용합니다. 접속 주소는 Gitea가 설치된 환경에 따라 달라집니다.

* **로컬 환경 (내 PC):** `http://localhost:3000`
* **가상 머신 (VMware/VirtualBox):** VM의 IP 주소를 확인한 후 접속합니다.
* 확인 명령어: `ip addr` (예: 192.168.56.101)
* 접속 주소: `http://192.168.56.101:3000`


* **클라우드 서버 (AWS/GCP):** 서버의 Public IP를 확인합니다.
* 접속 주소: `http://[Public-IP]:3000`



---

### 3. 접속이 안 될 때 점검 및 해결 (Troubleshooting)

만약 "사이트에 연결할 수 없음" 메시지가 뜬다면 다음 두 가지를 반드시 확인해야 합니다.

#### 3.1. 시스템 방화벽 확인 (Linux)

리눅스 자체 방화벽에서 3000번 포트를 차단하고 있을 가능성이 매우 높습니다.

```bash
# Ubuntu UFW 기준
sudo ufw allow 3000/tcp

# CentOS/RHEL Firewalld 기준
sudo firewall-cmd --permanent --add-port=3000/tcp
sudo firewall-cmd --reload

```

#### 3.2. 클라우드 보안 그룹(Security Group) 확인 (**AWS 유료 서비스 관련**)

AWS EC2를 사용 중이라면 인스턴스의 **보안 그룹(Security Group)** 설정에서 **Inbound 규칙**에 3000번 포트를 추가해야 합니다.

* **Type:** Custom TCP
* **Port Range:** 3000
* **Source:** 0.0.0.0/0 (또는 본인 IP)

### 4. 표준 설치 절차 (안정적인 운영을 위한 권장 방식)

단순히 `./gitea web`만 실행하면 터미널을 닫을 때 서비스가 종료됩니다. 운영 환경에서는 별도의 시스템 계정을 생성하고 디렉터리 구조를 갖추는 것이 '제대로 된' 설치법입니다.

#### 4.1. 시스템 계정 및 디렉터리 생성

Gitea를 실행할 전용 사용자(`git`)를 생성하여 보안을 강화합니다.

```bash
# git 사용자 생성
sudo adduser --system --shell /bin/bash --group --disabled-password --home /home/git git

# 필요한 디렉터리 생성 및 권한 부여
sudo mkdir -p /var/lib/gitea/{custom,data,log}
sudo chown -R git:git /var/lib/gitea/
sudo chmod -R 750 /var/lib/gitea/
sudo mkdir /etc/gitea
sudo chown root:git /etc/gitea
sudo chmod 770 /etc/gitea

```

#### 4.2. 실행 파일을 표준 경로로 이동

```bash
sudo cp gitea /usr/local/bin/gitea

```

#### 4.3. Systemd 서비스 등록 (자동 재시작 설정)

서버가 켜질 때 자동으로 Gitea가 실행되도록 설정합니다.
`/etc/systemd/system/gitea.service` 파일을 생성하고 아래 내용을 넣습니다.

```ini
[Unit]
Description=Gitea
After=network.target

[Service]
RestartSec=2s
Type=simple
User=git
Group=git
WorkingDirectory=/var/lib/gitea/
ExecStart=/usr/local/bin/gitea web --config /etc/gitea/app.ini
Restart=always

[Install]
WantedBy=multi-user.target

```

```bash
# 서비스 활성화 및 시작
sudo systemctl enable gitea
sudo systemctl start gitea

```

### 5. 인프라 비용 및 서비스 안내

* **AWS 서비스 이용 시 주의:** Gitea 서버를 24시간 구동하기 위해 EC2 인스턴스를 유지할 경우, 인스턴스 사양(t3.micro 등)에 따라 **월별 컴퓨팅 비용**이 발생합니다. 또한 데이터를 저장하는 **EBS 볼륨 용량**에 따라 추가 과금이 발생할 수 있으니 프리티어 사용량을 확인하시기 바랍니다.
