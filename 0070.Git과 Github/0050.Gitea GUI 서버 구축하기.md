명령어 실행 결과 `gitea: Is a directory`라는 에러가 발생하는 이유는 현재 작업 디렉토리에 **`gitea`라는 이름의 디렉토리(폴더)가 이미 존재하기 때문**입니다. `wget -O gitea` 옵션은 다운로드한 파일의 이름을 `gitea`라는 **파일**로 저장하라는 의미인데, 같은 이름의 폴더가 있어 충돌이 발생한 것입니다.

---

### 해결 방법

상황에 따라 아래 방법 중 하나를 선택하여 해결할 수 있습니다.

#### 방법 1: 실행 파일 이름을 다르게 지정 (권장)

디렉토리 이름과 겹치지 않도록 실행 파일 뒤에 버전을 붙이거나 이름을 변경하여 다운로드합니다.

```bash
# 파일명을 gitea-bin 으로 지정하여 다운로드
wget -O gitea-bin https://dl.gitea.com/gitea/1.22.3/gitea-1.22.3-linux-amd64

# 실행 권한 부여
chmod +x gitea-bin

```

#### 방법 2: 기존 디렉토리 삭제 후 다시 시도

만약 `gitea` 디렉토리가 필요 없는 빈 폴더이거나 잘못 생성된 것이라면, 삭제 후 다시 명령어를 실행합니다.

```bash
# 디렉토리 내용 확인
ls -ld gitea

# 디렉토리 삭제 (중요 데이터가 없는지 반드시 확인!)
rm -rf gitea

# 다시 다운로드 실행
wget -O gitea https://dl.gitea.com/gitea/1.22.3/gitea-1.22.3-linux-amd64

```

#### 방법 3: 디렉토리 안으로 이동하여 다운로드

만약 `gitea` 디렉토리가 Gitea 관련 파일들을 모아두는 용도라면, 해당 폴더 안으로 들어가서 파일명 옵션 없이 다운로드합니다.

```bash
cd gitea
wget https://dl.gitea.com/gitea/1.22.3/gitea-1.22.3-linux-amd64
mv gitea-1.22.3-linux-amd64 gitea
chmod +x gitea

```

### Gitea 바이너리 설치 시 주의사항

* **버전 확인**: 사용자가 입력한 `1.25.3` 버전은 현재 존재하지 않는 버전일 수 있습니다. (2026년 기준 최신 안정 버전은 `1.22.x` 시리즈일 가능성이 높으므로 [공식 다운로드 페이지](https://dl.gitea.com/gitea/)에서 실제 버전을 확인하십시오.)
* **실행 권한**: 바이너리를 다운로드한 후에는 반드시 `chmod +x` 명령어로 실행 권한을 주어야 서비스로 등록하거나 직접 실행할 수 있습니다.
