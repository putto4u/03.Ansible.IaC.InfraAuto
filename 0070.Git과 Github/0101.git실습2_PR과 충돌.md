# Chapter 35. 실무 입문용 협업 시나리오 상세 분석 및 가이드



### 1. 기능 개발 및 PR 전송 (Feature Branch Workflow)

```bash
# 새로운 기능 개발을 위한 독립된 작업 공간(브랜치)을 만듭니다.
# -b 옵션은 '생성'과 '이동'을 동시에 수행합니다.
git checkout -b feature/login

# 실제 작업 내용(파일 생성)을 작성합니다.
echo "Login Logic" > login.txt

# 새로 만든 파일을 Git의 추적 대상(Staging Area)에 올립니다.
git add login.txt

# 현재까지의 작업 내용을 로컬 저장소에 확정 기록합니다.
git commit -m "feat: add login core logic"

# 내 PC에만 있는 브랜치를 원격 서버(GitHub/GitLab)로 처음 업로드합니다.
# -u(upstream) 옵션은 로컬과 원격 브랜치를 연결하여 다음부터는 'git push'만 쳐도 되게 합니다.
git push -u origin feature/login

```

### 2. 긴급 상황 및 Stash 활용 (Context Switching)

실무에서는 현재 하던 작업을 커밋하기에는 코드가 지저분하거나 미완성인데, 급하게 다른 브랜치로 넘어가야 할 때가 많습니다.

```bash
# 아직 완성되지 않은 코드(WIP: Work In Progress)를 추가합니다.
echo "working on main logic..." >> main.txt

# 커밋하지 않은 채로 브랜치를 옮기면 에러가 나거나 코드가 꼬일 수 있습니다.
# 이때 현재 수정 사항을 임시 보관함(Stash)에 안전하게 저장합니다.
git stash push -m "WIP: main logic"

# 이제 작업 공간이 깨끗해졌으므로 메인 브랜치로 이동할 수 있습니다.
git checkout main

# 서버에 있는 최신 소스코드를 내 로컬로 가져와서 동기화합니다.
git pull origin main

# (여기서 버그 수정 작업을 진행했다고 가정)

# 다시 원래 하던 작업 브랜치로 돌아옵니다.
git checkout feature/login

# 서랍(Stash)에 넣어두었던 미완성 코드를 꺼내어 현재 파일들에 다시 입힙니다.
# pop은 꺼낸 후 보관함에서 해당 내역을 지웁니다.
git stash pop

```

### 3. 의도적인 충돌 해결 (Conflict Resolution)

협업의 꽃이라 불리는 충돌 해결 단계입니다. Git이 자동으로 합칠 수 없는 '같은 줄 수정' 상황을 해결합니다.

```bash
# A라는 사람이 먼저 수정해서 올린 상태에서, B라는 내가 같은 파일을 고치고 pull을 받으면
# Git은 아래와 같이 충돌 메시지를 띄우며 중단됩니다.
git pull origin main

# [Conflict 발생!] 에러 메시지가 뜨면 해당 파일을 에디터로 엽니다.
# <<<<<<< HEAD와 ======= 사이는 서버(남)의 코드이고,
# =======와 >>>>>>> 사이는 내(Local) 코드입니다.

# 1. 파일을 직접 수정하여 특수 기호들을 지우고 최종 합의된 코드를 남깁니다.
# 2. 수정이 끝났다면 Git에게 해결 완료를 알립니다.
git add README.md

# 3. 충돌 해결을 마무리하는 커밋을 생성합니다.
git commit -m "fix: resolve conflict in README"

# 4. 이제 안전하게 서버에 올립니다.
git push origin main

```

### 4. 실전 가이드: 충돌을 줄이는 3계명

| 수칙 | 내용 | 효과 |
| --- | --- | --- |
| **자주 Pull 하기** | 작업 시작 전과 도중에 `git pull`을 습관화합니다. | 동료와의 코드 차이를 최소화합니다. |
| **작은 커밋 단위** | 한 번에 너무 많은 파일을 고치지 않고 작게 나눕니다. | 충돌 범위가 좁아져 해결이 쉬워집니다. |
| **명확한 업무 분담** | 같은 파일의 같은 함수를 건드리지 않도록 사전에 소통합니다. | 근본적인 충돌 원인을 제거합니다. |
