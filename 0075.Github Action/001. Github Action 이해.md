## GitHub Actions의 이해와 주요 메뉴 구성

GitHub Actions는 GitHub 저장소 내에서 소프트웨어 개발 워크플로우를 자동화해주는 **CI/CD(지속적 통합 및 지속적 배포)** 플랫폼입니다. 코드를 푸시하거나 Pull Request를 생성하는 등의 이벤트가 발생할 때 자동으로 테스트를 실행하거나, AWS와 같은 클라우드 환경에 코드를 배포하는 작업을 수행합니다.

---

### 1. GitHub Actions의 핵심 개념

워크플로우를 구성하는 5가지 주요 요소입니다.

* **Workflows**: 하나 이상의 작업을 실행하는 자동화된 전체 프로세스입니다. `.github/workflows` 디렉토리에 YAML 파일로 저장됩니다.
* **Events**: 워크플로우를 트리거하는 특정 활동입니다. (예: `push`, `pull_request`, `schedule` 등)
* **Jobs**: 동일한 실행기(Runner)에서 실행되는 일련의 스텝(Steps) 집합입니다. 기본적으로 여러 Job은 병렬로 실행됩니다.
* **Steps**: 작업을 수행하는 최소 단위로, 커맨드를 실행하거나 **Action**을 호출합니다.
* **Actions**: 복잡하고 자주 반복되는 작업을 수행하기 위해 재사용 가능한 애플리케이션 플랫폼입니다. (예: `actions/checkout`, `aws-actions/configure-aws-credentials`)
* **Runners**: 워크플로우가 실행되는 서버입니다. GitHub에서 제공하는 호스팅 러너나 직접 구축한 자체 호스팅 러너를 사용할 수 있습니다.

---

### 2. GitHub Actions 주요 메뉴 설명

GitHub 저장소 상단의 **[Actions]** 탭을 클릭하면 나타나는 화면 구성입니다.

| 메뉴 항목 | 설명 |
| --- | --- |
| **Workflows** | 왼쪽 사이드바에 표시되며, 현재 저장소에 정의된 모든 YAML 워크플로우 파일 목록을 보여줍니다. |
| **All workflows** | 모든 워크플로우의 실행 이력을 통합하여 타임라인 순으로 보여줍니다. |
| **Workflow runs** | 특정 워크플로우의 실행 기록을 보여줍니다. 클릭 시 각 Job의 성공/실패 여부와 상세 로그를 확인할 수 있습니다. |
| **New workflow** | 새로운 워크플로우를 생성합니다. GitHub에서 제공하는 다양한 템플릿(Node.js, Python, Terraform 등)을 선택할 수 있습니다. |

---

### 3. 설정 및 보안 관련 메뉴 (Settings > Actions)

Actions의 동작 세부 사항을 제어하는 관리 메뉴입니다.

* **General**: 워크플로우 실행 권한(Permissions)을 설정합니다. 타사 Action 허용 여부나 Fork된 저장소의 실행 정책을 결정합니다.
* **Runners**: 자체적으로 운영하는 서버(Self-hosted runner)를 추가하고 관리합니다.
* **Secrets and variables**: API 키나 AWS Access Key 같은 민감 정보를 안전하게 저장합니다.
* **Secrets**: 암호화된 환경 변수로, 로그에 노출되지 않습니다.
* **Variables**: 암호화되지 않은 일반 구성 변수입니다.



---

### 4. AWS 연동 시 유료 서비스 및 과금 주의사항

GitHub Actions를 AWS와 연동하여 배포할 때 다음 과금 요소에 유의해야 합니다.

* **GitHub Actions 사용료 (유료 전환)**:
* 퍼블릭 저장소는 **무료**입니다.
* 프라이빗 저장소는 매월 일정 시간(Free 계정 기준 2,000분)의 무료 사용량을 제공하며, 이를 초과할 경우 **분당 과금**이 발생합니다. (Windows/macOS 러너는 Linux보다 과금 배율이 높습니다.)


* **AWS 리소스 생성 비용 (유료)**: 워크플로우를 통해 EC2, RDS, Lambda 등을 생성하거나 업데이트하는 경우, 해당 리소스의 **시간당 이용료**가 발생합니다.
* **AWS 인프라 프로비저닝 (IaC)**: Terraform이나 CloudFormation을 Actions로 실행하여 리소스를 생성할 때, 실수로 고사양 인스턴스를 생성하면 즉시 과금이 시작됩니다.
* **Secrets Manager 연동 (유료)**: Actions에서 AWS의 Secrets Manager에 저장된 값을 실시간으로 불러오는 단계를 포함할 경우, **API 호출당 비용**이 발생합니다.
