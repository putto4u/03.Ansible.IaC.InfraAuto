## 2. sudo 권한(Become) 패스워드 자동 대응
가장 흔히 발생하는 문제는 become: true를 사용할 때 서버가 유저의 패스워드를 요구하는 경우입니다. 이를 해결하기 위해 두 가지 전략을 사용합니다.

방법 A: 대상 서버의 NOPASSWD 설정 (권장)
대상 서버(Ubuntu)에서 sudo 명령을 내릴 때 패스워드를 묻지 않도록 설정하는 것이 가장 깔끔한 표준 방식입니다. AWS Ubuntu 인스턴스는 기본적으로 이 설정이 되어 있습니다.

Bash
# 서버측 설정 확인 (/etc/sudoers)
ubuntu ALL=(ALL) NOPASSWD:ALL
