## VS Code 실무 가이드: 기본 사용법, 자주 쓰는 편의 기능 및 꿀팁

본 가이드는 **[Visual Studio Code](https://code.visualstudio.com/)**(VS Code)의 기본 사용 방법부터 실무 기준의 편의 기능과 꿀팁을 체계적으로 정리한 교재입니다. Windows 운영체제 단축키를 기본으로 하며, macOS 사용자는 `Ctrl` 키를 `Cmd` 키로 대응하여 학습하시기 바랍니다.

추가로, VS Code 공식 문서의 “Tips and Tricks”를 병행하여 학습하면 숙련도를 빠르게 높일 수 있습니다. [Source](https://code.visualstudio.com/docs/getstarted/tips-and-tricks)

---

### 1. VS Code 기본 구조 및 용어 익히기

VS Code의 인터페이스는 크게 5가지 핵심 영역으로 구분됩니다.

* **Activity Bar(좌측 아이콘 바):** 탐색기, 검색, Git, 디버그, 확장(Extensions) 등 주요 뷰를 전환합니다.
* **Side Bar(좌측 패널):** 파일 트리(Explorer)나 Git 변경 파일 목록 등 세부 정보를 표시합니다.
* **Editor(중앙 편집 영역):** 실제 코드를 작성하는 공간이며, 탭을 통해 여러 파일을 동시에 열 수 있습니다.
* **Panel(하단):** 터미널, 문제(Errors), 출력, 디버그 콘솔 등이 위치합니다.
* **Status Bar(하단 바):** 현재 브랜치, 줄/열 위치, 언어 모드, 포맷터 상태 등을 표시합니다.

전체 UI 개념에 대한 상세 내용은 다음 문서를 참조하십시오. [Source](https://code.visualstudio.com/docs/getstarted/userinterface)

---

### 2. 생산성의 핵심: Command Palette (명령 팔레트)

VS Code의 거의 모든 기능은 명령 팔레트에서 검색하여 실행할 수 있습니다.

* **단축키:** `Ctrl + Shift + P` (또는 `F1`)
* **활용 예시:** “Format Document”, “Open Settings (JSON)”, “Git: Checkout to…” 등을 입력하여 즉시 실행합니다.
* 공식 문서에서도 VS Code의 핵심 진입점으로 명령 팔레트를 강조하고 있습니다. [Source](https://code.visualstudio.com/docs/getstarted/tips-and-tricks)

---

### 3. 파일/탭/프로젝트(Workspace) 사용법

* **폴더 열기:** 단일 프로젝트 작업 시 사용하는 일반적인 방식입니다.
* **Workspace(.code-workspace):** 여러 폴더를 하나의 VS Code 창에서 관리할 때 사용하며, 모노레포나 프론트엔드와 백엔드를 동시에 관리하기에 용이합니다.
* 설정은 “User 설정”과 “Workspace 설정”으로 구분되며, Workspace 설정이 프로젝트별로 우선 적용되는 구조입니다. [Source](https://code.visualstudio.com/docs/configure/settings)

---

### 4. 실무 편집 기술 (생산성 강화)

실무에서 가장 빈도가 높은 기능들을 중심으로 구성되었습니다.

#### 4.1 멀티 커서 및 멀티 선택

* `Alt + Click` : 원하는 위치에 커서를 추가로 생성합니다.
* `Ctrl + D` : 현재 선택한 단어와 동일한 다음 단어를 순차적으로 선택합니다.
* `Ctrl + Shift + L` : 문서 내 동일한 단어를 모두 선택합니다.
* 관련 상세 기능은 공식 편집 가이드에서 확인할 수 있습니다. [Source](https://code.visualstudio.com/docs/editing/codebasics)

#### 4.2 코드 탐색 및 빠른 보기

* `F12` : 정의로 이동 (Go to Definition)
* `Alt + F12` : 작은 팝업 창으로 정의 미리보기 (Peek Definition)
* `Shift + F12` : 참조된 모든 위치 찾기 (Find All References)
* (참고: 해당 기능은 언어별 확장 프로그램 및 프로젝트 설정에 따라 동작이 달라질 수 있습니다.)

#### 4.3 강력한 검색 기능

* `Ctrl + P` : 파일명을 일부만 입력하여 빠르게 열기 (Quick Open)
* `Ctrl + Shift + F` : 프로젝트 전체 검색 (정규식, 대소문자 구분, 파일 포함/제외 필터 지원)

### 5. 코드 품질 관리: Format / Lint / IntelliSense

#### 5.1 문서 포맷 (자동 정렬)

* “Format Document”를 실행하여 코드를 정렬합니다. 실무에서는 보통 Prettier와 같은 확장을 활용하여 팀 표준을 맞춥니다. [Source](https://code.visualstudio.com/docs/editing/codebasics)

#### 5.2 IntelliSense (지능형 코드 완성)

* 자동 완성, 파라미터 안내, 퀵 인포 등의 기능을 통칭합니다. [Source](https://code.visualstudio.com/docs/editing/intellisense)

---

### 6. 내장 터미널 활용

VS Code 내에서 터미널을 실행하여 프로젝트 명령을 즉시 처리할 수 있습니다.

* **활용:** `npm ci`, `npm test`, `git status`, `python -m venv` 등 수행
* 터미널 기본 가이드: [Source](https://code.visualstudio.com/docs/terminal/basics)

---

### 7. Git 연동 및 소스 제어

기본 내장된 Git UI를 통해 다음 작업을 수행할 수 있습니다.

* 변경 파일 확인 및 스테이징(add)
* 커밋(commit) 및 브랜치 전환/생성
* 관련 작업은 주로 “Source Control” 패널에서 진행됩니다.

---

### 8. 디버깅 (Debugging)

VS Code는 강력한 디버깅 인터페이스를 제공합니다.

* 브레이크포인트 설정 및 Step Over/Into 제어
* 변수 상태 및 콜스택 확인
* `launch.json` 파일을 통한 맞춤형 실행 설정
* 디버깅 개요: [Source](https://code.visualstudio.com/docs/debugtest/debugging)
* 디버그 설정 상세: [Source](https://code.visualstudio.com/docs/debugtest/debugging-configuration)

---

### 9. 설정(Settings) 커스터마이징

설정은 GUI 방식 외에도 JSON 파일을 직접 편집하여 세밀하게 제어할 수 있습니다.

* **User Settings (JSON):** `Ctrl + Shift + P` → “Open User Settings (JSON)”
* **Workspace Settings (JSON):** 프로젝트별 특정 설정 적용
* 공식 설정 가이드: [Source](https://code.visualstudio.com/docs/configure/settings)
