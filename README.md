# Class 3. 앤서블을 이용한 IaC 코드 인프라 자동화



Ansible을 이용한 **IaC(Infrastructure as Code)**는 인프라 자동화를 구현하는 핵심적인 **방법론**이자 **도구**의 결합을 의미합니다. 단순히 수동 작업을 줄이는 것을 넘어, 인프라를 **코드**로 정의하고 관리함으로써 시스템의 **일관성, 반복 가능성, 버전 관리**를 확보하는 것입니다.



## 1. IaC (Infrastructure as Code)의 정의와 목표

**IaC**는 서버, 데이터베이스, 네트워크 등 인프라 환경 전체를 **스크립트나 정의 파일** 형태로 관리하는 접근 방식입니다.

| 목표 | 설명 |
| :--- | :--- |
| **일관성 확보** | 모든 환경(개발, 테스트, 운영)을 동일한 코드로 생성하여 환경 간 차이로 발생하는 오류(Dependency Mismatch)를 방지합니다. |
| **반복 가능성** | 언제든 코드를 재실행하여 인프라를 처음부터 빠르게 재생성할 수 있습니다. |
| **버전 관리** | Git과 같은 도구를 사용하여 인프라의 모든 변경 이력을 추적하고, 필요한 경우 이전 상태로 롤백할 수 있습니다. |

---

## 2. Ansible이 IaC에서 수행하는 역할

Ansible은 IaC를 구현하는 대표적인 **구성 관리(Configuration Management)** 도구입니다.

### 2.1. 코드 작성 및 실행

Ansible은 **YAML** 형식의 **플레이북(Playbook)**을 사용하여 인프라의 최종 상태를 정의합니다. 이 플레이북이 바로 인프라를 정의하는 "코드"입니다.

| 요소 | 설명 | 예시 |
| :--- | :--- | :--- |
| **플레이북 (Code)** | YAML 형식으로 작성된 인프라 정의 파일. 실행할 작업과 대상을 선언. | "웹 서버 그룹에 Nginx를 설치하고 서비스 시작" |
| **인벤토리 (Target)** | 자동화 대상 서버들의 목록 및 그룹 정의 파일. | `[webservers]` 그룹에 서버 IP 주소 목록 정의 |
| **모듈 (Action)** | 실제 작업을 수행하는 내장 기능(패키지 설치, 파일 복사 등). | `ansible.builtin.apt` (패키지 관리), `ansible.builtin.copy` (파일 복사) |

### 2.2. 핵심 원칙: 멱등성 (Idempotence)

Ansible IaC의 가장 중요한 특징은 **멱등성**입니다.

* 플레이북을 **반복해서 실행**하더라도, 대상 서버가 **이미 원하는 상태**라면 Ansible은 **아무런 추가 작업을 하지 않고** 완료됩니다.
* 이는 운영 환경에서 인프라 코드를 안전하게 수시로 재실행하여 상태를 검증하고 유지하는 데 필수적입니다.

### 2.3. 에이전트리스 방식

Ansible은 관리 대상 서버에 별도의 **에이전트(Agent)** 설치가 필요 없습니다. 표준 프로토콜인 **SSH** (리눅스/유닉스)나 **WinRM** (윈도우)을 사용하기 때문에 인프라에 대한 설정 부담이 적습니다.

## 3. IaC 코드 인프라 자동화의 실전 활용

Ansible을 이용한 IaC는 다음과 같은 영역에서 인프라 자동화를 구현합니다.

1.  **구성 관리 (Configuration Management)**:
    * 신규 서버에 특정 애플리케이션(Nginx, Apache, MariaDB 등)을 설치하고 설정 파일을 배포합니다.
    * 서버에 필요한 사용자 계정, 권한, 보안 정책(예: 방화벽 설정)을 일관되게 적용합니다.
2.  **프로비저닝 (Provisioning)**:
    * AWS, Azure, GCP 등 클라우드 모듈을 사용하여 **가상 머신(VM) 인스턴스 자체**나 네트워크 자원(VPC, 서브넷)을 코드로 생성합니다.
3.  **지속적 배포 (Continuous Delivery, CD)**:
    * 개발 단계에서 완성된 애플리케이션 코드를 운영 서버로 **자동으로 배포**하고, 서비스 재시작(Rolling Update)을 안전하게 처리합니다.

이처럼 Ansible IaC는 인프라 관리의 수고를 줄여줄 뿐 아니라, 모든 인프라 변경 사항을 코드를 통해 투명하게 관리하여 **운영 효율성**과 **시스템 신뢰도**를 극대화하는 전문적인 기술입니다.
