## Nginx-Django-MySQL 3-Tier 아키텍처 자동화 프로젝트

이 프로젝트는 **Nginx(프론트엔드)**, **Django(백엔드)**, **MySQL(데이터베이스)**을 분리하여 구축하고, 외부에서 다운로드한 `employees` DB 마이그레이션 데이터를 Django API를 통해 웹 브라우저에 시각화하는 전체 과정을 다룹니다.

---

### 1. 프로젝트 개요 및 특장점

* **3-Tier 계층 분리**: 프레젠테이션(Nginx), 애플리케이션(Django), 데이터(MySQL) 계층을 분리하여 보안과 확장성을 확보합니다.
* **동적 데이터 마이그레이션**: Ansible을 통해 인터넷에서 `employees` DB를 자동으로 다운로드하고 마스터 DB에 주입합니다.
* **비동기 데이터 통신**: Nginx가 정적 페이지를 서비스하고, 브라우저가 JavaScript(Fetch API)로 Django 백엔드에 데이터를 요청하여 화면을 갱신합니다.
* **자동화된 프록시 설정**: Nginx가 API 요청(`@api`)만 골라 Django 서버(Gunicorn)로 전달하도록 리버스 프록시를 자동 구성합니다.

### 2. 프로젝트 디렉토리 구조

```text
django-3tier-project/
├── inventory.yml                # N대 서버 IP 및 그룹 정의

└── roles/
    ├── mysql_db/                # DB 설치 및 마이그레이션
    │   ├── tasks/main.yml
    │   └── templates/my.cnf.j2
    ├── django_backend/          # Django API 개발 및 배포
    │   ├── tasks/main.yml
    │   └── templates/settings.py.j2
    └── nginx_frontend/          # Nginx 프록시 및 HTML 배포
        ├── tasks/main.yml
        ├── templates/nginx.conf.j2
        └── files/index.html

```

### 3. 주요 역할별 소스 코드 (주석 포함)

#### ① 인벤토리 설정 (`inventory.yml`)

```yaml
all:
  children:
    db_server:                    # 데이터 계층
      hosts:
        db_01: { ansible_host: 192.168.30.101 }
    app_server:                   # 애플리케이션 계층 (Django)
      hosts:
        app_01: { ansible_host: 192.168.30.102 }
    web_server:                   # 프레젠테이션 계층 (Nginx)
      hosts:
        web_01: { ansible_host: 192.168.30.103 }

```

#### ② DB 마이그레이션 로직 (`roles/mysql_db/tasks/main.yml`)

```yaml
---
- name: MySQL 설치 및 외부 접속 허용
  ansible.builtin.apt:
    name: mysql-server
    state: present

- name: 마이그레이션 데이터(test_db) 다운로드
  ansible.builtin.git:
    repo: 'https://github.com/datacharmer/test_db.git'
    dest: /tmp/test_db

- name: Employees 데이터 주입 실행           # 마스터 DB에 샘플 데이터 마이그레이션
  ansible.builtin.shell:
    cmd: mysql -t < employees.sql
    chdir: /tmp/test_db
  changed_when: true

- name: Django용 DB 계정 생성                # 백엔드가 접속할 전용 계정 생성
  mysql_user:
    name: django_user
    password: "password123"
    priv: "employees.*:ALL"
    host: "%"
    state: present

```

#### ③ Django 백엔드 설정 (`roles/django_backend/tasks/main.yml`)

```yaml
---
- name: Python 필수 패키지 설치
  ansible.builtin.apt:
    name: [python3-pip, python3-django, libmysqlclient-dev]
    state: present

- name: Django 프로젝트 및 앱 생성
  ansible.builtin.shell:
    cmd: django-admin startproject myproject .
    creates: manage.py

- name: settings.py 템플릿 배포              # DB 접속 정보(IP, 계정) 자동 주입
  ansible.builtin.template:
    src: settings.py.j2
    dest: ./myproject/settings.py

- name: Django 서버(Gunicorn) 실행           # 백엔드 프로세스 가동
  ansible.builtin.shell:
    cmd: gunicorn --bind 0.0.0.0:8000 myproject.wsgi:application &

```

#### ④ Nginx 프론트엔드 설정 (`roles/nginx_frontend/tasks/main.yml`)

```yaml
---
- name: Nginx 설치 및 기본 설정 제거
  ansible.builtin.apt:
    name: nginx
    state: present

- name: 리버스 프록시 설정 배포               # /api 요청을 Django로 전달하는 설정
  ansible.builtin.template:
    src: nginx.conf.j2
    dest: /etc/nginx/sites-available/default
  notify: Restart Nginx

- name: 프론트엔드 index.html 배포           # 데이터를 표로 보여줄 HTML/JS 배포
  ansible.builtin.copy:
    src: index.html
    dest: /var/www/html/index.html

```

#### ⑤ 프론트엔드 데이터 시각화 (`files/index.html`)

```html
<table>
    <thead>
        <tr><th>사번</th><th>성</th><th>이름</th><th>입사일</th></tr>
    </thead>
    <tbody id="emp-table">
        </tbody>
</table>

<script>
    fetch('/api/employees/')                 /* Nginx 프록시를 통해 Django API 호출 */
    .then(res => res.json())
    .then(data => {
        const table = document.getElementById('emp-table');
        data.forEach(emp => {
            table.innerHTML += `<tr><td>${emp.emp_no}</td><td>${emp.last_name}</td><td>${emp.first_name}</td><td>${emp.hire_date}</td></tr>`;
        });
    });
</script>

```

### 4. AWS 운영 및 과금 가이드

* **인스턴스 비용 (3대 이상)**: 3-Tier 구성을 위해 최소 3대의 EC2가 필요합니다. 프리티어(`t2.micro`) 사용 시 시간당 비용은 무료이나, **3대 동시 가동 시 약 10일(250시간 x 3)** 만에 한 달치 무료 시간(750시간)이 소진되므로 주의하세요.
* **유료 서비스 알림 (RDS)**:
* 직접 구축 대신 AWS RDS를 사용할 경우 **시간당 약 $0.017 (db.t3.micro 기준)**의 비용이 발생하며, 이는 프리티어 한도와 별개로 계산될 수 있으니 확인이 필요합니다.


* **보안 그룹(Security Group) 계층화**:
* **Web SG**: 80(HTTP) 허용 (Source: 0.0.0.0/0)
* **App SG**: 8000(Django) 허용 (Source: Web SG ID)
* **DB SG**: 3306(MySQL) 허용 (Source: App SG ID)


* **자원 회수**: 실습이 종료되면 모든 인스턴스를 반드시 **Terminate(종료)** 하여 추가 과금을 방지하십시오.
