## 동적 DB 연동 웹 애플리케이션 개발 및 배포 프로젝트

이 프로젝트는 이전 단계에서 구축한 N대의 웹 서버에 PHP 애플리케이션을 배포하여, 마이그레이션된 DB 서버로부터 실시간 데이터를 조회하는 기능을 구현합니다. 로드 밸런서를 통해 접속 시 웹 서버 N대가 교대로 DB 데이터를 가져와 상위 20명의 직원 정보를 표 형식으로 출력합니다.

---

### 1. 서비스 아키텍처 및 흐름

1. **사용자 요청**: 로드 밸런서(LB) IP로 접속합니다.
2. **부하 분산**: LB가 인벤토리에 정의된 N대의 웹 서버 중 하나로 요청을 전달합니다.
3. **DB 쿼리**: 요청을 받은 웹 서버는 PHP를 사용하여 DB 서버(Master 혹은 Slave)에 접속합니다.
4. **데이터 출력**: `employees` 테이블에서 사번, 이름, 부서, 연봉 정보를 상위 20명까지 조회하여 HTML 표(Table)로 렌더링합니다.

---

### 2. 프로젝트 디렉토리 구조

```text
web-db-integration/
├── inventory.yml                # 웹 서버 N대 및 DB 서버 정보
├── deploy_app.yml               # PHP 앱 배포용 플레이북
└── templates/
    └── index.php.j2             # DB 접속 정보가 동적으로 할당될 PHP 템플릿

```

### 3. 주요 파일별 소스 코드

#### ① PHP 애플리케이션 템플릿 (`templates/index.php.j2`)

Ansible의 변수(`hostvars`)를 사용하여 DB 마스터 서버의 IP를 자동으로 주입합니다.

```php
<?php
$servername = "{{ hostvars[groups['db_master'][0]]['ansible_host'] }}";
$username = "repl_user";
$password = "password123";
$dbname = "employees";

// DB 연결
$conn = new mysqli($servername, $username, $password, $dbname);

if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}

// 상위 20명 조회 쿼리 (JOIN을 통해 부서 및 연봉 정보 포함)
$sql = "SELECT e.emp_no, e.first_name, e.last_name, d.dept_name, s.salary 
        FROM employees e 
        JOIN dept_emp de ON e.emp_no = de.emp_no 
        JOIN departments d ON de.dept_no = d.dept_no 
        JOIN salaries s ON e.emp_no = s.emp_no 
        WHERE s.to_date = '9999-01-01'
        LIMIT 20";

$result = $conn->query($sql);
?>

<!DOCTYPE html>
<html>
<head>
    <title>Employee Data List</title>
    <style>
        table { border-collapse: collapse; width: 100%; }
        th, td { border: 1px solid #ddd; padding: 8px; text-align: left; }
        th { background-color: #f2f2f2; }
        .server-info { color: blue; font-weight: bold; }
    </style>
</head>
<body>
    <h2>직원 정보 리스트 (Top 20)</h2>
    <p>현재 응답 중인 웹 서버: <span class="server-info"><?php echo gethostname(); ?></span></p>
    
    <table>
        <tr>
            <th>사번</th>
            <th>이름</th>
            <th>부서</th>
            <th>연봉</th>
        </tr>
        <?php
        if ($result->num_rows > 0) {
            while($row = $result->fetch_assoc()) {
                echo "<tr>
                        <td>" . $row["emp_no"]. "</td>
                        <td>" . $row["first_name"] . " " . $row["last_name"] . "</td>
                        <td>" . $row["dept_name"]. "</td>
                        <td>$" . number_format($row["salary"]) . "</td>
                      </tr>";
            }
        } else {
            echo "<tr><td colspan='4'>데이터가 없습니다.</td></tr>";
        }
        $conn->close();
        ?>
    </table>
</body>
</html>

```

#### ② 배포 플레이북 (`deploy_app.yml`)

웹 서버에 PHP 필수 모듈을 설치하고 제작한 `index.php`를 N대의 서버에 배포합니다.

```yaml
---
- name: 웹 서버 PHP 애플리케이션 배포
  hosts: web_servers
  become: yes
  tasks:
    - name: PHP 및 MySQL 커넥터 설치
      ansible.builtin.apt:
        name: 
          - php
          - php-mysql
        state: present
        update_cache: yes

    - name: PHP 애플리케이션 템플릿 배포 (N대 공통)
      ansible.builtin.template:
        src: templates/index.php.j2
        dest: /var/www/html/index.php
        mode: '0644'

    - name: 기본 index.html 제거 (PHP 우선순위 보장)
      ansible.builtin.file:
        path: /var/www/html/index.html
        state: absent

    - name: Apache 재시작
      ansible.builtin.service:
        name: apache2
        state: restarted

```

### 4. AWS 운영 및 과금 가이드

* **EC2 데이터 전송 비용**: 웹 서버가 DB 서버로부터 데이터를 가져올 때, 서로 다른 가용 영역(AZ)에 있다면 **Regional Data Transfer** 비용이 발생합니다.
* **NAT Gateway 과금**: 웹 서버가 PHP 패키지를 설치하기 위해 외부 인터넷에 접속할 때, Private Subnet에 있다면 NAT Gateway 시간당 요금과 데이터 처리 비용이 발생하므로 유의하십시오.
* **ELB(Load Balancer) 과금**: 사용자가 웹 사이트에 접속하여 표를 조회할 때마다 LCU(Load Balancer Capacity Units)에 따른 비용이 산정됩니다.
* **유료 전환 주의**: 마이그레이션된 DB가 크고 쿼리가 복잡할 경우 RDS나 EC2 DB의 I/O 수치가 높아져 추가 비용이 발생할 수 있습니다.
