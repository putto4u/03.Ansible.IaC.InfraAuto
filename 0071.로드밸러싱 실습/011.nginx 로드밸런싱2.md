기존에 작성 중이던 교재 내용에 요청하신 **동적 핸들러(Dynamic Handler)**와 **디렉토리 최적화**를 적용하여 수정해 드립니다. 여러 서비스(Web, LB, DB 등)가 늘어나도 핸들러 코드는 단 하나만 존재하도록 설계되었습니다.

## Ansible Role 기반 Nginx 웹 서버 및 로드 밸런서 분리 구축 프로젝트

이번 프로젝트는 실무 표준 방식인 **Role(역할) 구조**를 채택하여 설계되었습니다. 특히 서비스 재시작 로직을 변수화하여, 여러 역할에서 공통으로 발생하는 핸들러를 **전역 동적 핸들러(Global Dynamic Handler)**로 통합함으로써 코드 중복을 완벽히 제거했습니다.

---

### 1. 프로젝트 디렉토리 구조 (최적화)

각 역할마다 중복된 핸들러 파일을 두지 않고, 프로젝트 루트의 `handlers/` 폴더 내 단 하나의 파일로 모든 서비스를 제어합니다.

```text
nginx-role-project/
├── inventory.yml                 # 전체 서버 그룹 및 IP 정의
├── deploy_site.yml               # 전체 시스템 구축용 메인 플레이북
├── handlers/                     # [통합] 전역 동적 핸들러
│   └── main.yml                  # 모든 서비스 재시작을 처리하는 단일 코드
├── roles/                        # 역할별 로직 보관함
│   ├── webserver/
│   │   └── tasks/
│   │       └── main.yml          # 웹 서버 설치 및 index.html 생성
│   └── loadbalancer/
│       ├── tasks/
│       │   └── main.yml          # LB 설치 및 설정 배포
│       └── templates/
│           └── lb_nginx.conf.j2  # LB 설정 템플릿

```

---

### 2. 주요 파일별 소스 코드

#### ① 인벤토리 파일 (`inventory.yml`)

각 그룹별로 재시작할 서비스 이름(`service_name`)과 동작(`service_action`)을 변수로 정의합니다.

```yaml
all:
  children:
    load_balancer:
      hosts:
        lb_node:
          ansible_host: 192.168.10.100
      vars:
        service_name: "nginx"
        service_action: "restarted"
    web_servers:
      hosts:
        web_01:
          ansible_host: 192.168.10.101
        web_02:
          ansible_host: 192.168.10.102
      vars:
        service_name: "nginx"
        service_action: "reloaded"

```

#### ② 통합 동적 핸들러 (`handlers/main.yml`)

이 코드는 서비스 이름을 고정하지 않고 변수를 받아 실행하므로, DB나 다른 서버가 추가되어도 이 코드 하나로 대응이 가능합니다.

```yaml
---
- name: "Unified Dynamic Service Handler"
  ansible.builtin.service:
    name: "{{ service_name }}"
    state: "{{ service_action | default('restarted') }}"
  listen: "trigger_restart"

```

#### ③ 메인 플레이북 (`deploy_site.yml`)

플레이북 하단에서 통합 핸들러를 한 번만 로드합니다.

```yaml
---
- name: 백엔드 웹 서버 계층 배포
  hosts: web_servers
  become: true
  roles:
    - webserver

- name: 전면 로드 밸런서 계층 배포
  hosts: load_balancer
  become: true
  roles:
    - loadbalancer

  handlers:
    - import_tasks: handlers/main.yml

```

#### ④ 웹 서버 역할 태스크 (`roles/webserver/tasks/main.yml`)

```yaml
---
- name: Nginx 웹 서버 패키지 설치
  ansible.builtin.apt:
    name: nginx
    state: present
    update_cache: true

- name: 서버별 개별 식별 페이지 생성
  ansible.builtin.copy:
    content: "<h1>Hello! This is {{ inventory_hostname }}</h1>"
    dest: /var/www/html/index.html
    mode: '0644'
  notify: "trigger_restart"  # 전역 listen 토픽 호출

```

#### ⑤ 로드 밸런서 역할 태스크 (`roles/loadbalancer/tasks/main.yml`)

```yaml
---
- name: Nginx 로드 밸런서 패키지 설치
  ansible.builtin.apt:
    name: nginx
    state: present
    update_cache: true

- name: 로드 밸런싱 설정 템플릿 배포
  ansible.builtin.template:
    src: lb_nginx.conf.j2
    dest: /etc/nginx/conf.d/load_balancer.conf
    mode: '0644'
  notify: "trigger_restart"  # 동일한 listen 토픽 호출

```

### 3. AWS 운영 시 과금 및 보안 가이드

* **EC2 고정 비용**: 3대의 인스턴스가 상시 가동됩니다. 프리티어 종료 시 시간당 비용이 청구됩니다.
* **공인 IP (EIP) 과금**: 인스턴스 중지 시에도 연결된 EIP가 있으면 시간당 약 **$0.005**가 부과됩니다.
* **보안 그룹 최적화**:
* **LB SG**: 포트 80을 전체(`0.0.0.0/0`) 개방합니다.
* **Web SG**: 포트 80을 **LB의 보안 그룹 ID**로부터의 트래픽만 허용하여 보안을 강화합니다.


* **자원 회수**: 실습 종료 후 반드시 인스턴스를 **Terminate(종료)** 하십시오.
