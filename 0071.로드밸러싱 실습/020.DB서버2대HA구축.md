## MySQL 2대 기반 고가용성(HA) 및 로드 밸런싱 실습 프로젝트

이 프로젝트는 대규모 클러스터 구축 전, 가장 핵심이 되는 **2대의 DB 서버**를 활용하여 **마스터-슬레이브(Master-Slave) 복제**와 **읽기/쓰기 분리**의 기초를 학습하기 위해 설계되었습니다. 이전 웹 서버 프로젝트와 동일한 Role 구조를 사용하여 향후 통합이 용이합니다.

---

### 1. 프로젝트 개요 및 특장점

* **최소 규모의 HA 구성**: 2대의 서버만으로 데이터 동기화(Replication)와 부하 분산의 원리를 파악합니다.
* **역할 명확화**: 1번 서버는 쓰기(Master), 2번 서버는 읽기(Slave) 역할을 수행하도록 구성하여 흐름을 단순화했습니다.
* **실무형 설정**: 서버 대수가 적더라도 실무에서 사용하는 설정 방식(Server-ID, Read-Only 등)을 그대로 적용합니다.
* **비용 최적화**: 서버 수량을 최소화하여 AWS 프리티어 환경에서 부담 없이 실습할 수 있습니다.

### 2. 프로젝트 디렉토리 구조

```text
mysql-basic-project/
├── inventory.yml                # DB 서버 2대의 IP 정의
├── deploy_db.yml                # DB 구축 메인 플레이북
└── roles/
    ├── mysql_common/            # 공통 설치 및 보안 설정
    │   └── tasks/main.yml
    ├── mysql_master/            # 1번 서버(Master) 설정
    │   └── tasks/main.yml
    └── mysql_slave/             # 2번 서버(Slave) 설정
        └── tasks/main.yml

```

### 3. 주요 파일별 소스 코드 (주석 포함)

#### ① 인벤토리 파일 (`inventory.yml`)

```yaml
all:
  children:
    db_master:                   # 쓰기 전용 마스터 그룹
      hosts:
        db_01:                   # 1번 서버
          ansible_host: 192.168.20.101
    db_slave:                    # 읽기 전용 슬레이브 그룹
      hosts:
        db_02:                   # 2번 서버
          ansible_host: 192.168.20.102

```

#### ② DB 공통 역할 (`roles/mysql_common/tasks/main.yml`)

```yaml
---
- name: MySQL 서버 패키지 설치              # MySQL 소프트웨어 설치
  ansible.builtin.apt:
    name: mysql-server
    state: present
    update_cache: true

- name: 외부 접속 허용 설정                 # 모든 IP에서 접속 가능하도록 바인드 수정
  ansible.builtin.lineinfile:
    path: /etc/mysql/mysql.conf.d/mysqld.cnf
    regexp: '^bind-address'
    line: 'bind-address = 0.0.0.0'
  notify: Restart MySQL

- name: MySQL 서비스 활성화                # 서비스 상시 가동 설정
  ansible.builtin.service:
    name: mysql
    state: started
    enabled: true

```

#### ③ 마스터 설정 (`roles/mysql_master/tasks/main.yml`)

```yaml
---
- name: 마스터 서버 고유 ID 부여            # 복제를 위한 서버 식별자(1) 설정
  ansible.builtin.lineinfile:
    path: /etc/mysql/mysql.conf.d/mysqld.cnf
    regexp: '^#?server-id'
    line: 'server-id = 1'
  notify: Restart MySQL

- name: 바이너리 로그 활성화                # 데이터 변경 이력을 기록 (복제의 원천)
  ansible.builtin.lineinfile:
    path: /etc/mysql/mysql.conf.d/mysqld.cnf
    regexp: '^#?log_bin'
    line: 'log_bin = /var/log/mysql/mysql-bin.log'
  notify: Restart MySQL

```

#### ④ 슬레이브 설정 (`roles/mysql_slave/tasks/main.yml`)

```yaml
---
- name: 슬레이브 서버 고유 ID 부여           # 마스터와 중복되지 않는 ID(2) 설정
  ansible.builtin.lineinfile:
    path: /etc/mysql/mysql.conf.d/mysqld.cnf
    regexp: '^#?server-id'
    line: 'server-id = 2'
  notify: Restart MySQL

- name: 읽기 전용 모드 적용                 # 실수로 데이터를 수정하지 못하게 방어
  ansible.builtin.lineinfile:
    path: /etc/mysql/mysql.conf.d/mysqld.cnf
    line: 'read_only = 1'
    insertafter: '[mysqld]'
  notify: Restart MySQL

```

### 4. AWS 운영 및 과금 가이드

* **서버 수량 (2대)**: 웹 서버 프로젝트(3대)와 합쳐도 총 5대 규모입니다. 8대 구성에 비해 프리티어 시간을 훨씬 여유롭게 사용할 수 있습니다.
* **유료 전환 주의**:
* **EBS 스토리지**: 각 인스턴스에 할당된 디스크 용량 합계가 30GB를 넘지 않도록 주의하세요 (예: 각 8GB 할당 시 총 16GB로 안전).
* **공인 IP**: 실행 중인 인스턴스에 할당된 IP는 대당 약 **$0.005/시간**의 비용이 발생할 수 있습니다.


* **보안 그룹**: 마스터와 슬레이브 모두 **3306 포트**를 열되, 보안을 위해 **웹 서버의 보안 그룹 ID**만 접속할 수 있게 설정하는 것이 중요합니다.
* **자원 종료**: 실습이 끝나면 반드시 **Terminate(종료)**를 통해 인스턴스와 볼륨을 모두 삭제해 주세요.
