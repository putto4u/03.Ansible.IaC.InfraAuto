## MySQL 고가용성 DB 클러스터 통합 구축 가이드 (주석 포함)

이 가이드는 이전 **Nginx/Web 서버 프로젝트**와 구조적으로 완벽히 호환되도록 설계되었습니다. **쓰기(Master) 이중화**와 **읽기(Slave) 로드 밸런싱**을 위한 모든 설정 파일에 상세 주석을 추가했습니다.

---

### 1. 인벤토리 설정 파일 (`inventory.yml`)

서버 대수가 늘어나도 그룹 내에 호스트를 추가하기만 하면 자동으로 확장되는 구조입니다.

```yaml
all:                                      # 최상위 그룹 정의
  children:                               # 하위 그룹 섹션
    db_master:                            # [쓰기 전용] 마스터 서버 그룹 (데이터 변경 처리)
      hosts:                              # 개별 호스트 목록
        db_master_01:                     # 마스터 1번 서버
          ansible_host: 192.168.20.101    # 마스터 1번 IP
        db_master_02:                     # 마스터 2번 서버 (이중화용)
          ansible_host: 192.168.20.102    # 마스터 2번 IP
    db_slave:                             # [읽기 전용] 슬레이브 서버 그룹 (조회 부하 분산)
      hosts:                              # 개별 호스트 목록
        db_slave_01:                      # 슬레이브 1번 서버
          ansible_host: 192.168.20.103    # 슬레이브 1번 IP
        db_slave_02:                      # 슬레이브 2번 서버
          ansible_host: 192.168.20.104    # 슬레이브 2번 IP
        db_slave_03:                      # 슬레이브 3번 서버
          ansible_host: 192.168.20.105    # 슬레이브 3번 IP

```

---

### 2. DB 공통 역할 (`roles/mysql_common/tasks/main.yml`)

모든 DB 서버에 공통적으로 적용되는 기본 설치 및 네트워크 설정입니다.

```yaml
---
- name: MySQL 서버 패키지 설치              # 모든 노드에 MySQL 설치
  ansible.builtin.apt:
    name: mysql-server                    # 설치할 패키지명
    state: present                        # 설치 상태 확인
    update_cache: true                    # 저장소 인덱스 최신화

- name: 외부 접속을 위한 바인드 주소 변경      # 기본 127.0.0.1을 0.0.0.0으로 변경하여 외부 접속 허용
  ansible.builtin.lineinfile:             # 텍스트 파일 내용 수정 모듈
    path: /etc/mysql/mysql.conf.d/mysqld.cnf # 설정 파일 경로
    regexp: '^bind-address'               # 찾을 문구 패턴
    line: 'bind-address = 0.0.0.0'        # 교체할 문구 (모든 IP 허용)
  notify: Restart MySQL                   # 수정 발생 시 서비스 재시작 예약

- name: MySQL 서비스 자동 실행 등록          # 부팅 시 자동 시작 및 현재 상태 시작 유지
  ansible.builtin.service:
    name: mysql                           # 서비스 이름
    state: started                        # 현재 실행 중 상태 보장
    enabled: true                         # 부팅 시 자동 시작 활성화

```

### 3. 마스터 서버 역할 (`roles/mysql_master/tasks/main.yml`)

데이터의 원본을 관리하고 복제를 위한 설정을 담당합니다.

```yaml
---
- name: 마스터 고유 서버 ID 설정             # 복제 환경에서 각 서버를 식별하는 ID 부여
  ansible.builtin.lineinfile:
    path: /etc/mysql/mysql.conf.d/mysqld.cnf
    regexp: '^#?server-id'                # server-id 설정 행을 찾음
    line: "server-id = {{ inventory_hostname_short | regex_replace('[^0-9]', '') | default(1) }}" 
    # 호스트 이름에서 숫자를 추출하여 고유 ID 자동 생성
  notify: Restart MySQL

- name: 복제용 바이너리 로그 활성화          # 변경 사항을 기록하여 슬레이브가 가져갈 수 있게 함
  ansible.builtin.lineinfile:
    path: /etc/mysql/mysql.conf.d/mysqld.cnf
    regexp: '^#?log_bin'
    line: 'log_bin = /var/log/mysql/mysql-bin.log' # 로그 저장 경로 설정
  notify: Restart MySQL

```

---

### 4. 슬레이브 서버 역할 (`roles/mysql_slave/tasks/main.yml`)

읽기 요청을 처리하기 위한 복제 전용 설정입니다.

```yaml
---
- name: 슬레이브 고유 서버 ID 설정            # 마스터와 중복되지 않는 고유 ID 부여
  ansible.builtin.lineinfile:
    path: /etc/mysql/mysql.conf.d/mysqld.cnf
    regexp: '^#?server-id'
    line: "server-id = {{ (inventory_hostname_short | regex_replace('[^0-9]', '') | int) + 100 }}" 
    # 마스터와 겹치지 않게 숫자에 100을 더해 자동 생성
  notify: Restart MySQL

- name: 읽기 전용 모드 활성화                # 데이터 무결성을 위해 슬레이브에서는 직접 쓰기 차단
  ansible.builtin.lineinfile:
    path: /etc/mysql/mysql.conf.d/mysqld.cnf
    line: 'read_only = 1'                 # 읽기 전용 설정 추가
    insertafter: '[mysqld]'               # [mysqld] 섹션 아래 삽입
  notify: Restart MySQL

```

### [과금 및 주의사항]

1. **인스턴스 개수 (유료 전환 주의)**:
* 현재 구성은 **총 5대**의 DB 서버(마스터 2, 슬레이브 3)입니다.
* AWS 프리티어는 매월 750시간의 무료 사용을 제공하지만, 5대를 동시에 켜두면 약 **6일 만에 무료 한도가 소진**됩니다. 실습 후에는 반드시 **Terminate(종료)** 하세요.


2. **AWS 유료 서비스 (RDS)**:
* **AWS RDS**: 직접 구축하는 대신 RDS를 쓰면 **읽기 복제본(Read Replica)** 기능을 클릭 한 번으로 제공합니다.
* 하지만 RDS 인스턴스 당 시간당 요금이 EC2보다 비싸며, 인스턴스 5대를 RDS로 운영할 경우 **상당한 유료 요금**이 발생할 수 있습니다.


3. **보안 그룹 (Security Group)**:
* **포트 3306**: 오직 **웹 서버(Web SG)** 그룹에서 오는 접속만 허용하여 데이터 유출을 막아야 합니다.


4. **스토리지 (EBS)**:
* DB 데이터가 쌓이는 용량만큼 비용이 청구됩니다. 실습 시에는 기본 8GB로 충분합니다.
